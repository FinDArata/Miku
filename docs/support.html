Support

Something wrong, or an idea for Miku? Here’s how to get help.
Report a bug or request a feature: open an issue on GitHub (fastest).
Email: github.com/FinDArata/Miku/issues

FAQ

Where is the Windows download?

Here: Miku-Windows.msi or Miku-Windows-setup.exe, always the newest version (Windows 10/11). The installer isn’t code-signed yet, so SmartScreen may warn you: click More info → Run anyway. Microsoft Defender once flagged it by mistake; Microsoft reviewed it and removed the detection. If Defender still blocks it, update its definitions and try again.

Is there a Linux version?

Yes: an AppImage, a .deb and a .rpm for x86_64, in Miku for Linux 0.5.0 (an Arch package can be built from the repository). The island sits on the top edge with compositors that support layer-shell (COSMIC, KDE Plasma, Hyprland, Sway…); on GNOME it sits at the top of the screen through XWayland. Please report anything odd in the issues.

Miku doesn’t show my Claude Code sessions

Open Settings → Claude Code → Install hooks, review the changes, confirm, then start a new Claude Code session.

Can I use Miku with Gemini CLI or Antigravity (agy)?

Yes. Open Settings → Gemini CLI → Install hooks or Settings → Antigravity → Install hooks. The same backup-and-diff flow as Claude Code applies. Once installed, each gemini or agy session gets its own pill in the island.

The chat doesn’t answer

Add your API key in Settings: Settings → Anthropic API for Claude, or Settings → Chat — other providers for Google AI (Gemini) or OpenAI. API usage is billed by the provider, separately from any subscription.

An integration pill stays grey

Check its key in Settings. Up to 4 pills can be active at once in addition to the main workspace tool — see Settings → Active pills.

What are Active pills?

Active pills are the coding tools, agents and AI providers you declare in Settings → Active pills. The Main picker at the top lets you choose your primary workspace tool (VS Code, Cursor, Codex or Antigravity). You can then add up to 4 more pills: Gemini CLI, Anthropic, Google AI, OpenAI and service integrations. An agent that sends miku_agent in its hook payload still gets its own automatic pill regardless.

Can I use Miku with Cursor?

Yes. Install the Claude Code hooks (Settings → Claude Code → Install hooks). Claude Code started in Cursor's terminal then shows up on the Cursor pill, and its permission requests can be answered from the notch, like in VS Code. Cursor's own agent shows up too when Cursor loads Claude Code's hooks; its requests are still answered in Cursor. Pick Cursor as your Main tool if that's where you code.

Can I use Miku with Codex?

Yes. Open Settings → Codex Hooks → Install hooks. Miku shows you the changes to ~/.codex/hooks.json before writing anything. Once installed, open Codex and run /hooks, or open Hooks in Codex's settings, to review and trust the hooks — Codex asks for this once. After that, your Codex sessions show up on the Codex pill, and permission requests show up with Allow and Deny in the notch.

No sound

Check the speaker icon in the notch header and the volume in Settings.

Which model does the chat use?

Claude by default (Anthropic). Switch provider and model by clicking the model name above the chat box. For Anthropic, the model can also be set in Settings → Anthropic API. Each model is billed at its own price by the provider.

Can I use Ollama or LM Studio instead of a cloud API?

Yes. Open Settings → Chat → Local models, type the server address (or leave blank for the default), and click Connect. Miku checks that the server is reachable and lists available models. To stop using it, click Disconnect. No API key is needed; it is free: the model runs on your computer.

How do I uninstall?

Remove hooks first: Settings → Claude Code → Uninstall, and if you installed them, also Settings → Gemini CLI → Uninstall and Settings → Antigravity → Uninstall. If you installed the Plan usage status line (Settings → Agents → Plan usage), click Uninstall there first to restore your previous status line.

On Windows: same Uninstall button for the hooks, then Windows Settings → Apps → Miku → Uninstall. Optionally delete %LOCALAPPDATA%\Miku.

On Linux: same Uninstall button for the hooks, then sudo apt remove miku or sudo dnf remove miku, or delete the AppImage. Optionally delete ~/.config/miku, ~/.local/share/miku, ~/.local/share/com.findarata.kanon and ~/.cache/miku.

Questions fréquentes

Où est le téléchargement Windows ?

Ici : Miku-Windows.msi ou Miku-Windows-setup.exe, toujours la dernière version (Windows 10/11). L’installeur n’est pas encore signé, donc SmartScreen peut afficher un avertissement : clique sur Informations complémentaires → Exécuter quand même. Microsoft Defender l’avait détecté par erreur ; Microsoft l’a analysé et a retiré la détection. Si Defender le bloque encore, mets à jour ses définitions et réessaie.

Y a-t-il une version Linux ?

Oui : une AppImage, un .deb et un .rpm pour x86_64, dans Miku for Linux 0.5.0 (un paquet Arch se construit depuis le dépôt). L’island se place sur le bord du haut avec les compositeurs qui gèrent layer-shell (COSMIC, KDE Plasma, Hyprland, Sway…) ; sous GNOME, elle se place en haut de l’écran via XWayland. Signale tout souci dans les issues.

Miku n’affiche pas mes sessions Claude Code

Réglages → Claude Code → Install hooks, vérifie les changements, confirme, puis lance une nouvelle session Claude Code.

Puis-je utiliser Miku avec Gemini CLI ou Antigravity (agy) ?

Oui. Ouvre Réglages → Gemini CLI → Install hooks ou Réglages → Antigravity → Install hooks. Le même flux sauvegarde + diff qu’avec Claude Code s’applique. Une fois installé, chaque session gemini ou agy obtient sa propre pastille dans l’island.

Le chat ne répond pas

Ajoute ta clé d’API dans les Réglages : Réglages → Anthropic API pour Claude, ou Réglages → Chat — other providers pour Google AI (Gemini) ou OpenAI. L’API est facturée par le fournisseur, à part de tout abonnement.

Une pastille reste grise

Vérifie sa clé dans les Réglages. Jusqu’à 4 pastilles peuvent être actives en même temps, en plus de l’outil de code principal — voir Réglages → Active pills.

Qu’est-ce que les Active pills ?

Les Active pills sont les outils de code, agents et fournisseurs IA que tu déclares dans Réglages → Active pills. Le sélecteur Main en haut te permet de choisir ton outil principal (VS Code, Cursor, Codex ou Antigravity). Tu peux ensuite ajouter jusqu’à 4 pastilles supplémentaires : Gemini CLI, Anthropic, Google AI, OpenAI et des intégrations de services. Un agent qui envoie miku_agent dans son payload obtient quand même sa pastille automatique.

Puis-je utiliser Miku avec Cursor ?

Oui. Installe les hooks Claude Code (Réglages → Claude Code → Install hooks). Claude Code lancé dans le terminal de Cursor apparaît alors sur la pastille Cursor, et tu peux répondre à ses demandes d’autorisation depuis le notch, comme dans VS Code. L’agent de Cursor apparaît aussi quand Cursor charge les hooks de Claude Code ; ses demandes se règlent encore dans Cursor. Choisis Cursor comme outil principal si c’est là que tu codes.

Puis-je utiliser Miku avec Codex ?

Oui. Ouvre Réglages → Codex Hooks → Install hooks. Miku te montre les changements apportés à ~/.codex/hooks.json avant d’écrire quoi que ce soit. Une fois les hooks installés, ouvre Codex et tape /hooks, ou ouvre Hooks dans les réglages de l’app, pour les passer en revue et leur faire confiance — Codex ne te le demande qu’une fois. Ensuite, tes sessions Codex apparaissent sur la pastille Codex, et les demandes d’autorisation apparaissent avec Allow et Deny dans le notch.

Pas de son

Vérifie l’icône haut-parleur dans l’en-tête du notch et le volume dans les Réglages.

Quel modèle utilise le chat ?

Claude par défaut (Anthropic). Change de fournisseur et de modèle en cliquant sur le nom du modèle au-dessus du champ de chat. Pour Anthropic, le modèle peut aussi être défini dans Réglages → Anthropic API. Chaque modèle est facturé à son propre tarif par le fournisseur.

Puis-je utiliser Ollama ou LM Studio à la place d'une API cloud ?

Oui. Ouvre Réglages → Chat → Local models, entre l’adresse du serveur (ou laisse vide pour le défaut) et clique sur Connect. Miku vérifie que le serveur est accessible et liste les modèles disponibles. Pour arrêter, clique sur Disconnect. Pas de clé d’API — c’est gratuit : le modèle tourne sur ton ordinateur.

Comment désinstaller ?

Retire d’abord les hooks : Réglages → Claude Code → Uninstall, et si tu les as installés, aussi Réglages → Gemini CLI → Uninstall et Réglages → Antigravity → Uninstall. Si tu as installé le relais Plan usage (Réglages → Agents → Plan usage), clique sur Uninstall d’abord pour retrouver ta status line d’avant.

Sous Windows : le même bouton Uninstall pour les hooks, puis Paramètres Windows → Applications → Miku → Désinstaller. Tu peux aussi supprimer %LOCALAPPDATA%\Miku.

Sous Linux : le même bouton Uninstall pour les hooks, puis sudo apt remove miku ou sudo dnf remove miku, ou supprime l’AppImage. Tu peux aussi supprimer ~/.config/miku, ~/.local/share/miku, ~/.local/share/com.findarata.kanon et ~/.cache/miku.
